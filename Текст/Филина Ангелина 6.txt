1  Какую роль выполняет Unity в клиент-серверной схеме?
Unity выступает в роли клиента. Он отправляет HTTP-запросы, получает данные (JSON) от сервера и на их основе изменяет (перемещает) модель станка в сцене.
2 Какой HTTP-метод использует CncJsonController?
Используется метод GET. Он необходим для получения JSON с координатами станка. Метод POST в данном примере не используется.
3 Как найти координату X внутри массива data?
Нужно перебрать массив data, найти раздел с названием Оси Канала + channel (например, «Оси Канала 1»). Внутри него (в section 1) найти строку, где первый элемент равен "Перемещение по оси x", и взять значение из второго элемента этой строки (row 1 ).
4 Зачем удалять «мм» и заменять запятую точкой?
Удалить «мм»: чтобы очистить строку от единиц измерения и оставить только числа.Заменить запятую на точку: функция float.Parse с InvariantCulture в C# ожидает точку в качестве десятичного разделителя. Без замены программа выдаст ошибку формата.
5 Как назначить узлы X/Y/Z в Inspector?
Нужно выделить объект, на котором висит скрипт CncJsonController, найти в инспекторе поля Node X, Node Y и Node Z и перетащить в них соответствующие 3D-объекты (Transform) из иерархии сцены.
6 Зачем хранить начальные положения и использовать localPosition?
Хранение начальных положений (startX, startY, startZ): чтобы при получении новых координат рассчитывать положение узла как «начальная позиция + смещение». Это предотвращает бесконечное накопление движения при повторных запросах.Использование localPosition: потому что координаты станка задаются относительно родительского объекта (направления движения зависят от иерархии)
7 Куда направлены Vector3.forward и Vector3.up в Unity?
Vector3.forward — направлен вперед (вдоль оси Z).Vector3.up — направлен вверх (вдоль оси Y).
  (В контексте станка: forward используется для движения салазок по оси Y, а up — для движения шпиндельной головки по оси Z)
8 Почему повторный ответ не добавляет новое смещение?
Потому что в методе MoveNodes позиция узла каждый раз вычисляется заново по формуле: node.localPosition = start + Vector3.направление * значение. К сохраненной изначальной позиции прибавляется актуальное значение от сервера, а не текущее положение узла.
