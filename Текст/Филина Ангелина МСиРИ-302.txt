1Зачем скрывать поля класса?
Чтобы защитить внутреннее состояние объекта от некорректных изменений извне .Публичное поле позволяет любому коду напрямую изменить значение (например,сделать баланс отрицательным ),что приводит к ошибкам которые сложно отследить. Скрытие поля заставляет использовать другие методы для доступа ,где можно проверить корректность даннных.
2 Чем свойство отличается от поля?
Поле — это хранилище переменная внутри класса, где физически лежат данные. Оно обычно скрыто (private) и имеет имя с маленькой буквы.
Свойство — это (механизм доступа) ,член класса - умное поле не хранит значение (за редким исключением автосвойств)           
предоставляет get/set обычно public (интерфейс) имя - с заглавной буквы.
3 Что произойдёт, если не объявить ни одного конструктора?
Если конструктор не объявлен явно, компилятор автоматически сгенерирует конструктор по умолчанию без параметров пустой конструктор. Это позволяет создавать объекты через new, но поля при этом не будут инициализированы нужными значениями если у них нет значений по умолчанию, что может нарушить логику объекта.
4 Как конструктор связан с инкапсуляцией?
Конструктор гарантирует контроль создания объекта. Он вызывается один раз при создании и позволяет задать корректное начальное состояние объекта проверить входные данные и заполнить скрытые приватные поля. Таким образом, объект становится валидным с самого начала, и нельзя создать пустой или некорректный объект в обход правил класса. Вместе с приватными полями и контролируемыми свойствами конструктор образует надежный класс.
5 Можно ли изменить свойство только для чтения после создания объекта?
Нет. Свойство, доступное только для чтения у которого есть только get, как в примере public string Owner (get; ), инициализируется один раз обычно через конструктор и после этого его значение изменить нельзя. Попытка присвоить ему значение вызовет ошибку компиляции.
