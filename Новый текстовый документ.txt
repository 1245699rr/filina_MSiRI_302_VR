1 Класс — это шаблон (или чертеж), который описывающий состояние и какие методы поведение будут у будущих объектов. 
- задает , какие поля будут у объектов 
- задает , какие методы будут у объектов 
-  сам по себе данные не хранит 
Объект (экземпляр)— это конкретный сущность, созданный по шаблону класса. 
-  имеет свои собственные значения полей (состояние)
-  может выполнять методы (поведение)
-  объект создается в памяти с помощью оператора new.
2 Переменная например, var acc = new BankAccount(); хранит ссылку на объект в памяти, а не сами данные.
3 Ошибка времени выполнения.В Java это NullPointerException, в C# — NullReferenceException, в C++ — неопределённое поведение обычно падение программы.Программа аварийно завершится, если это исключение не обработано, так как null означает отсутствие объекта в памяти, и обращаться к его полям/методам невозможно.
4  Объединять поля и методы в одном классе.Это нужно для.Логической связности это данные поля и операции над ними методы находятся в одном месте, что делает код понятным и структурированным.Контроля доступа это класс может скрыть поля сделать их private и предоставить доступ только через методы, защищая данные от некорректного изменения извне.Упрощения сопровождения это изменение внутренней реализации класса не ломает код, который его использует, если публичный интерфейс методы  остаётся прежним.
